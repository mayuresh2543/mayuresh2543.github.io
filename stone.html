Clean Flash (First Time)

Follow these steps if you are coming from stock MIUI or a different custom ROM.

1. Boot to Fastboot

adb reboot bootloader

2. Flash Recovery

Flash the recommended recovery image (boot.img or recovery.img depending on the package):

fastboot flash boot <recovery_filename>.img

3. Reboot to Recovery

fastboot reboot recovery

4. Format Data

In Recovery, navigate to:

  • Factory Reset > Format Data / Factory Reset

Warning

This will permanently erase all your photos, files, and apps.

5. Sideload ROM

On the phone: Select Apply Update > Apply from ADB.
On your PC: Run the following command:

adb sideload <rom_filename>.zip

6. Finalize

  • If you want to flash GApps or Magisk: Go to Advanced > Reboot to Recovery and sideload them now.
  • Otherwise, go back to main menu and tap Reboot system now.

Update / Dirty Flash

Use any of these methods to update your current ROM to a newer version.

Method 1: OTA Update (Recommended)

  1. Go to Settings > System > Updater.
  2. Download and install the update.
  3. The device will reboot automatically.

Method 2: Local Update (Via App)

  1. Download the ROM zip and place it in internal storage.
  2. Open the Updater app.
  3. Tap the menu (3 dots) > Local Update.
  4. Select the zip file. The phone will reboot to recovery and install it.

Method 3: Manual Sideload

If you prefer using a PC or if OTA fails:

  1. Reboot to Recovery.
  2. Select Apply Update > Apply from ADB.
  3. On PC: 
    adb sideload <rom_filename>.zip
  4. (Optional) Reboot to recovery and re-flash Magisk/GApps if needed.
  5. Reboot System.
