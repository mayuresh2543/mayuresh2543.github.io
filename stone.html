Clean Flash (First Time Install)

Follow these steps carefully if you are coming from MIUI or another custom ROM.

1
Enter Fastboot Mode

Power off your device. Use the hardware button combo or run:

adb reboot bootloader
2
Flash Recovery

Flash the AOSP recovery image to the boot partition.

fastboot flash boot recovery_filename.img
3
Reboot to Recovery

Immediately reboot into the new recovery mode.

fastboot reboot recovery
4
Format Data

This will wipe your internal storage.

  1. On the recovery screen, select Factory Reset.
  2. Select Format Data / Factory Reset.
5
Sideload ROM

Connect phone to PC. On the phone, select Apply Update > Apply from ADB. On PC run:

adb sideload rom_filename.zip
6
Addons (Optional)

If you want to flash GApps or Magisk:

  1. When prompted after sideloading, select Yes to reboot to recovery.
  2. Sideload your GApps/Magisk zip file.
  3. Format Data again after flashing these addons.

If you are not flashing addons, select No when prompted.

7
Reboot

Select Reboot system now. The first boot may take several minutes.

Update Guide

Option 1: OTA Update (Automatic)

Go to Settings > System > Updater. Download, install, and click reboot.

Option 2: Local Update (Via Updater App)

  1. Place the new ROM .zip on internal storage.
  2. Open the Updater app.
  3. Tap the 3-dot menu and select Local Update.
  4. Select the ROM file. The phone will reboot to recovery and install automatically.

Option 3: Manual Dirty Flash (ADB Sideload)

If you prefer using ADB or need to re-flash addons:

  1. Boot into Recovery and select Apply Update > Apply from ADB.
  2. On PC run: adb sideload new_rom_filename.zip
  3. (Optional) Reboot to recovery and sideload GApps/Magisk if needed.
  4. Reboot to system.
