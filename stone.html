Clean Flash (First Time)

Follow these steps if you are coming from stock MIUI or a different custom ROM.

1. Boot to Fastboot

adb reboot bootloader

2. Flash Recovery

Flash the recommended recovery image:

fastboot flash boot <recovery_filename>.img

3. Reboot to Recovery

fastboot reboot recovery

4. Format Data

In Recovery, navigate to:

  • Factory Reset > Format Data / Factory Reset

Warning

This will permanently erase all your photos, files, and apps.

5. Sideload ROM

On the phone: Select Apply Update > Apply from ADB.
On your PC: Run the following command:

adb sideload <rom_filename>.zip

6. Finalize

Go back to main menu and tap Reboot system now.

Update Guide

Use any of these methods to update your current ROM.

Method 1: OTA Update (Recommended)

  1. Go to Settings > System > Updater.
  2. Download and install the update.

Method 2: Manual Sideload

If OTA fails, you can dirty flash via ADB:

adb sideload <rom_filename>.zip
